# X85 Web Port Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A faithful, fully playable browser version of X85 (2010) for desktop and mobile, deployed on Netlify, with source on GitHub.

**Architecture:** A zero-dependency TypeScript "Chien2D shim" (`web/src/engine/`) exposes the subset of the Chien2D 2 API the game uses, with the original function names, over WebGL2, Web Audio, Pointer/Keyboard/Gamepad events and localStorage. The game code (`web/src/game/`) is a function-by-function translation of `X85-devcore 2/*.cpp`, where every blocking `while(!encerra){…; C2D2_Sincroniza();}` loop becomes a generator that `yield`s once per frame, driven by a fixed 60 Hz loop. A Node build script turns the original `dados/` folder into web assets (images, collision masks, map spawn JSON, audio).

**Tech Stack:** TypeScript 5 (strict), Vite 7, Vitest 3, Playwright 1.5x, Node ≥ 20 (build scripts use only Node built-ins: `fs`, `path`, `zlib`, `child_process`), macOS `afconvert` for AAC.

**Spec:** `docs/superpowers/specs/2026-10-17-x85-web-port-design.md` (read it first). Ground truth for behaviour: `docs/analysis/01-game-spec.md` (game), `docs/analysis/02-engine-and-formats.md` (engine semantics), `docs/analysis/03-versions-and-assets.md` (assets).

## Review Focus

1. **Tab hidden / app backgrounded mid-game** → on return the game is paused (overlay), no burst of catch-up frames, no audio glitch. Test: Task 8 (`loop.test.ts` "hidden → no catch-up") + Task 15 e2e.
2. **Keys held while focus is lost** (keyup never arrives) → all buttons are released on `blur`/`visibilitychange`; the ship does not keep drifting. Test: Task 4 (`input.test.ts` "blur releases all").
3. **No user gesture yet (iOS/Chrome autoplay policy)** → no exceptions; sounds requested before unlock are silently dropped; music starts on the first tap/click/key. Test: Task 6 (`audio.test.ts` "play before unlock is a no-op").
4. **localStorage unavailable or corrupt** (Safari private mode, quota, garbage JSON) → game runs with defaults in memory, never throws. Test: Task 7 (`storage.test.ts` "throwing storage" + "corrupt JSON").
5. **Resize / orientation change / DPR change mid-game** → canvas re-letterboxes and pointer → logical mapping stays exact. Test: Task 8 (`viewport.test.ts` letterbox math) + Task 15 e2e (resize then click a menu button).

### Task 2: Asset pipeline (`tools/build-assets.mjs`)

**Files:**
- Create: `web/tools/png.mjs`, `web/tools/fmp.mjs`, `web/tools/build-assets.mjs`, `web/tests/unit/tools.test.ts`
- Output (committed, so deploy needs no macOS tools): `web/public/assets/**`, `web/public/assets/manifest.json`

**Interfaces:**
- Produces `manifest.json`:
```ts
interface Manifest {
  images: Record<string /* original path e.g. "./dados/jogo/nave.png" */, { url: string; w: number; h: number; mask: string /* url of .mask */ }>;
  sounds: Record<string /* original path */, { url: string }>;                // effects (WAV)
  music: Record<string /* original path */, { m4a: string; ogg: string }>;
  maps: Record<string /* e.g. "dados/jogo/mapas/fase1.fmp" */, { url: string }>;
}
```
  Keys are **exactly the path strings used in the C++ source** (both `./dados/...` and `dados/...` forms appear — register the string as written in the source; `build-assets` normalises by stripping a leading `./` and the engine's lookup does the same).
- `.mask` binary format: little-endian `Uint32` header `[w, h]`, then `h` rows of `ceil(w/32)` `Uint32` words; bit `x & 31` (LSB-first) of word `x >> 5` is 1 if the pixel is **solid**. Solid ⇔ `(r|g|b|a) != 0` after zeroing opaque magenta `(255,0,255,255)` (engine `PontoTransparente`, `02-engine §6`). JPG images: every pixel solid (the C loader gives alpha 255).
- Map JSON: `{ "width":25, "height":200, "tileW":32, "tileH":32, "markers": { "<code>": [[x,y],...] } }` where code = cell value − 1 and `[x,y]` = tile centre in map px, row-major order (`02-engine §10.2`).
- `png.mjs` exports `decodePng(buf: Buffer): { width, height, rgba: Uint8Array }` (color types 2 and 6, bit depth 8, non-interlaced, all 5 filter types; throw on anything else).
- `fmp.mjs` exports `parseFmp(buf: Buffer): { width, height, tileW, tileH, layer0: Int16Array }` and `markersOf(parsed, offset=1): Record<string, [number,number][]>`.

### Task 4: `engine/input.ts` — buttons with edge flags

**Files:** Create `web/src/engine/input.ts`, `web/tests/unit/input.test.ts`

**Interfaces:**
```ts
export const enum K { CIMA, BAIXO, DIREITA, ESQUERDA, ESC, F1, F2, F3, F4, A, B, C, D, E, F, G, H, I, J, K_, L, M, N, O, P, Q, R, S, T, U, V, W, X, Y, Z,
  N0, N1, N2, N3, N4, N5, N6, N7, N8, N9, ENTER, ESPACO, BACKSPACE, LALT, RALT, LCTRL, RCTRL, LSHIFT, RSHIFT, ENCERRA, MAXTECLAS }
// Order identical to chien2d2.h enum (C2D2_CIMA … C2D2_MAXTECLAS). (K_ = C2D2_K.)
export interface Botao { pressionado: boolean; ativo: boolean; liberado: boolean }
export interface Mouse { x: number; y: number; botoes: [Botao, Botao, Botao] } // MESQUERDO, MDIREITO, MMEIO
export type Evento = { t: 'down' | 'up'; k: K } | { t: 'mdown' | 'mup'; b: 0 | 1 | 2; x: number; y: number } | { t: 'mmove'; x: number; y: number } | { t: 'releaseAll' };
export class Entrada {
  teclas: Botao[];           // length MAXTECLAS
  mouse: Mouse;
  push(e: Evento): void;     // queue (from DOM handlers, touch, gamepad)
  poll(): void;              // = C2D2_Entrada: clear pressionado/liberado, then apply queued events in order
  typed: string[];           // characters typed this frame (for name entry on mobile) — cleared by poll()
}
export function codeToKeys(code: string): K[];   // KeyboardEvent.code → original key(s) + aliases (spec §5.1)
export function attachDom(e: Entrada, target: Window, mapPointer: (cx: number, cy: number) => { x: number; y: number }): () => void;
export function pollGamepads(e: Entrada, pads: (Gamepad | null)[], prev: { mask: number }): void; // diff → push down/up
```
Alias mapping (`codeToKeys`): `ArrowUp→CIMA` (+`KeyW`), `ArrowDown→BAIXO` (+`KeyS`), `ArrowLeft→ESQUERDA` (+`KeyA`), `ArrowRight→DIREITA` (+`KeyD`), `Space→ESPACO` (+`KeyJ`), `ControlLeft→LCTRL` (+`KeyX`,`KeyK`), `AltLeft→LALT` (+`KeyZ`,`KeyL`), `Escape→ESC`, `Enter→ENTER`, `Backspace→BACKSPACE`, `KeyA..KeyZ→A..Z` **also** (letters always produce their letter key too, for name entry; e.g. `KeyX` → `[X, LCTRL]`), digits → `N0..N9`, `ShiftLeft→LSHIFT`, etc. Gamepad: stick/dpad → arrows (deadzone 0.35), A(0)/RT(7) → ESPACO, B(1) → LCTRL, LB(4)/RB(5) → LALT, Start(9) → ESC.
DOM: `keydown` ignores `e.repeat`, calls `preventDefault()` for arrows, Space, Alt, Ctrl, Backspace, Tab when the target is not the `#texto` input; `blur` and `visibilitychange(hidden)` push `{t:'releaseAll'}`. Pointer: mouse-type pointers → `mmove/mdown/mup` via `mapPointer`; touch pointers are handled by Task 14, not here.

- Slicing §2: if `largura && altura` → frames `largura×altura`, `matrizX = trunc(W/largura)`, `matrizY = trunc(H/altura)`; else whole image is one frame. Frame `i`: `col = i % matrizX, row = trunc(i / matrizX)`; out of range or id 0 → return false, draw nothing.
- `DesenhaSprite` §3: integer `x,y` top-left, frame size, alpha 1.
- `DesenhaSpriteEfeito` §3: quad from `(x,y)` to `(x+w, y+h)`; negative `w`/`h` flips (UVs swapped) — the quad then extends left/up of `x,y`. Alpha `(alpha & 255)/255`.
- WebGL2Backend: context `{alpha:false, antialias:false, premultipliedAlpha:false, preserveDrawingBuffer:false}`; textures with `UNPACK_PREMULTIPLY_ALPHA_WEBGL=false`, `LINEAR` min/mag, `CLAMP_TO_EDGE`; blend `SRC_ALPHA, ONE_MINUS_SRC_ALPHA`; ortho 800×600 y-down; one dynamic VBO (pos.xy, uv.xy, alpha) sized for 4096 quads, `drawArrays(TRIANGLES)`; `pontos` = 1-px quads with a 1×1 white texture tinted (r,g,b)/255 — add a `cor` attribute (rgb) to the vertex format so points and sprites share a shader (sprites use cor=1,1,1). `limpa()` clears to opaque black. Handle `webglcontextlost` (preventDefault) / `webglcontextrestored` (recreate textures from retained images).
- Canvas stays 800×600 backing store; scaling is CSS-only (Task 8). This keeps 1:1 pixel output identical to the 2010 GL renderer.
- Collision §6, with the engine's word-combining bugs **fixed** (clean per-pixel AND): strict bounding-box reject (`x1 > x2+w2-1 || …` → no hit); then test overlapping pixels using each sprite's frame sub-rectangle of its image mask (frame origin `col*spLargura, row*spAltura`). Return true on first solid∧solid.
- Font §4: sprite set of `tamanho×tamanho`; metrics per glyph c (0..255) from the mask: `desloc` = first column with any solid pixel; `larg` = (first all-empty column after desloc) − desloc + pad, pad = 2 for size 32 (check `chien2d2.cpp:230-320` for the exact pad formula and the "no empty column" case = `tamanho - desloc`); empty glyph → `larg = tamanho, desloc = 0`; space → `tamanho/2`. Draw: `W = Σ larg`; pen = `x` (ESQUERDA), `x - W` (DIREITA), `x - trunc(W/2)` (CENTRALIZADO); each glyph at `(pen - desloc[c], y)`, `pen += larg[c]`. Text is Latin-1: use `charCodeAt(i) & 255`.
